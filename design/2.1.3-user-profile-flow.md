# 2.1.3 - Hồ Sơ Cá Nhân

## Mô tả
Tính năng cho phép độc giả xem và cập nhật thông tin cá nhân, đổi mật khẩu.

**Actor:** Độc giả  
**Yêu cầu:** Đăng nhập với vai trò độc giả

## Flowchart - Xem Hồ Sơ

```mermaid
flowchart TD
    Start([Độc giả truy cập trang hồ sơ]) --> CheckAuth{Đã đăng nhập?}
    CheckAuth -->|Không| RedirectLogin[Chuyển hướng tới trang đăng nhập]
    RedirectLogin --> End1([Kết thúc])
    
    CheckAuth -->|Có| CheckRole{Vai trò là độc giả?}
    CheckRole -->|Không| ErrorRole[Hiển thị lỗi:<br/>Không có quyền truy cập]
    ErrorRole --> End1
    
    CheckRole -->|Có| LoadData[Load thông tin người dùng]
    LoadData --> DisplayProfile[Hiển thị hồ sơ:<br/>- Tên, Email<br/>- Số điện thoại, Địa chỉ<br/>- Ngày tham gia<br/>- Số lần mượn<br/>- Tổng số tiền phạt]
    DisplayProfile --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style End1 fill:#ffcdd2
    style ErrorRole fill:#ffcdd2
```

## Flowchart - Cập Nhật Thông Tin

```mermaid
flowchart TD
    Start([Độc giả click Chỉnh sửa]) --> ShowEditForm[Hiển thị form chỉnh sửa]
    ShowEditForm --> InputData[Nhập thông tin mới:<br/>- Tên<br/>- Số điện thoại<br/>- Địa chỉ]
    InputData --> Validate{Validate dữ liệu}
    
    Validate -->|Tên trống hoặc >50 ký tự| ErrorName[Hiển thị lỗi:<br/>Tên không hợp lệ]
    ErrorName --> InputData
    
    Validate -->|Số điện thoại không đúng định dạng| ErrorPhone[Hiển thị lỗi:<br/>Số điện thoại không hợp lệ]
    ErrorPhone --> InputData
    
    Validate -->|Địa chỉ trống hoặc >255 ký tự| ErrorAddress[Hiển thị lỗi:<br/>Địa chỉ không hợp lệ]
    ErrorAddress --> InputData
    
    Validate -->|Tất cả hợp lệ| UpdateInfo[Cập nhật thông tin]
    UpdateInfo --> Success[Hiển thị thông báo:<br/>Cập nhật thành công]
    Success --> Refresh[Làm mới trang hồ sơ]
    Refresh --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style ErrorName fill:#ffcdd2
    style ErrorPhone fill:#ffcdd2
    style ErrorAddress fill:#ffcdd2
    style Success fill:#c8e6c9
```

## Flowchart - Đổi Mật Khẩu

```mermaid
flowchart TD
    Start([Độc giả click Đổi mật khẩu]) --> ShowPasswordForm[Hiển thị form đổi mật khẩu]
    ShowPasswordForm --> InputPassword[Nhập:<br/>- Mật khẩu cũ<br/>- Mật khẩu mới<br/>- Xác nhận mật khẩu mới]
    InputPassword --> Validate{Validate dữ liệu}
    
    Validate -->|Mật khẩu cũ trống| ErrorOldPassword[Hiển thị lỗi:<br/>Vui lòng nhập mật khẩu cũ]
    ErrorOldPassword --> InputPassword
    
    Validate -->|Mật khẩu mới <8 hoặc >16 ký tự| ErrorNewPassword[Hiển thị lỗi:<br/>Mật khẩu phải từ 8-16 ký tự]
    ErrorNewPassword --> InputPassword
    
    Validate -->|Xác nhận mật khẩu không khớp| ErrorConfirm[Hiển thị lỗi:<br/>Mật khẩu xác nhận không khớp]
    ErrorConfirm --> InputPassword
    
    Validate -->|Tất cả hợp lệ| CheckOldPassword{Mật khẩu cũ đúng?}
    CheckOldPassword -->|Không| ErrorWrongOld[Hiển thị lỗi:<br/>Mật khẩu cũ không đúng]
    ErrorWrongOld --> InputPassword
    
    CheckOldPassword -->|Đúng| CheckSame{Mật khẩu mới trùng<br/>mật khẩu cũ?}
    CheckSame -->|Có| ErrorSame[Hiển thị lỗi:<br/>Mật khẩu mới phải khác mật khẩu cũ]
    ErrorSame --> InputPassword
    
    CheckSame -->|Không| UpdatePassword[Cập nhật mật khẩu]
    UpdatePassword --> Success[Hiển thị thông báo:<br/>Đổi mật khẩu thành công]
    Success --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style ErrorOldPassword fill:#ffcdd2
    style ErrorNewPassword fill:#ffcdd2
    style ErrorConfirm fill:#ffcdd2
    style ErrorWrongOld fill:#ffcdd2
    style ErrorSame fill:#ffcdd2
    style Success fill:#c8e6c9
```

## Validation Rules
- **Tên:** Không được để trống, tối đa 50 ký tự
- **Số điện thoại:** Định dạng số điện thoại hợp lệ
- **Địa chỉ:** Không được để trống, tối đa 255 ký tự
- **Mật khẩu mới:** Tối thiểu 8 ký tự, tối đa 16 ký tự, phải khác mật khẩu cũ

## Edge Cases
- Số điện thoại không đúng định dạng
- Địa chỉ quá dài (>255 ký tự)
- Mật khẩu mới trùng với mật khẩu cũ
- Mật khẩu cũ sai
