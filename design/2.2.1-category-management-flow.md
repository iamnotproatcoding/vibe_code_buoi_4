# 2.2.1 - Quản lý thể loại sách

## Mô tả
Tính năng cho phép nhân viên thư viện quản lý các thể loại sách: xem, thêm, sửa, xóa.

**Actor:** Nhân viên thư viện  
**Yêu cầu:** Đăng nhập với vai trò nhân viên

## Flowchart - Xem Danh Sách

```mermaid
flowchart TD
    Start([Nhân viên truy cập trang quản lý thể loại]) --> CheckAuth{Đã đăng nhập<br/>vai trò nhân viên?}
    CheckAuth -->|Không| RedirectLogin[Chuyển hướng tới trang đăng nhập]
    RedirectLogin --> End1([Kết thúc])
    
    CheckAuth -->|Có| LoadCategories[Load danh sách thể loại]
    LoadCategories --> DisplayTable[Hiển thị danh sách dạng bảng<br/>có thể sửa trực tiếp]
    DisplayTable --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style End1 fill:#ffcdd2
```

## Flowchart - Thêm Thể Loại

```mermaid
flowchart TD
    Start([Nhân viên click Thêm thể loại sách]) --> ShowForm[Hiển thị form thêm thể loại]
    ShowForm --> InputName[Nhập tên thể loại]
    InputName --> Validate{Validate dữ liệu}
    
    Validate -->|Tên trống| ErrorEmpty[Hiển thị lỗi:<br/>Tên thể loại không được để trống]
    ErrorEmpty --> InputName
    
    Validate -->|Tên >50 ký tự| ErrorLength[Hiển thị lỗi:<br/>Tên thể loại tối đa 50 ký tự]
    ErrorLength --> InputName
    
    Validate -->|Tất cả hợp lệ| CheckDuplicate{Tên thể loại<br/>đã tồn tại?}
    CheckDuplicate -->|Có| ErrorDuplicate[Hiển thị lỗi:<br/>Tên thể loại đã tồn tại]
    ErrorDuplicate --> InputName
    
    CheckDuplicate -->|Không| CreateCategory[Tạo thể loại mới]
    CreateCategory --> Success[Hiển thị thông báo:<br/>Thêm thể loại thành công]
    Success --> Refresh[Làm mới danh sách]
    Refresh --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style ErrorEmpty fill:#ffcdd2
    style ErrorLength fill:#ffcdd2
    style ErrorDuplicate fill:#ffcdd2
    style Success fill:#c8e6c9
```

## Flowchart - Xóa Thể Loại

```mermaid
flowchart TD
    Start([Nhân viên click Xóa trên bảng]) --> CheckBooks{Có sách nào<br/>thuộc thể loại này?}
    CheckBooks -->|Có| ErrorHasBooks[Hiển thị lỗi:<br/>Không thể xóa thể loại<br/>đang có sách]
    ErrorHasBooks --> End1([Kết thúc])
    
    CheckBooks -->|Không| ShowConfirm[Hiển thị xác nhận xóa]
    ShowConfirm --> UserConfirm{Người dùng<br/>xác nhận?}
    UserConfirm -->|Không| Cancel[Hủy xóa]
    Cancel --> End1
    
    UserConfirm -->|Có| DeleteCategory[Xóa thể loại]
    DeleteCategory --> Success[Hiển thị thông báo:<br/>Xóa thể loại thành công]
    Success --> Refresh[Làm mới danh sách]
    Refresh --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style End1 fill:#ffcdd2
    style ErrorHasBooks fill:#ffcdd2
    style Success fill:#c8e6c9
```

## Validation Rules
- **Tên thể loại:** Không được để trống, tối đa 50 ký tự, không được trùng

## Edge Cases
- Tên thể loại quá dài (>50 ký tự)
- Tên thể loại trống
- Tên thể loại trùng với thể loại khác
- Xóa thể loại đang được sử dụng (có sách thuộc thể loại)
