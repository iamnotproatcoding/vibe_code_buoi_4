# 2.6.1 - Danh Sách Người Dùng

## Mô tả
Tính năng cho phép quản lý viên xem danh sách người dùng, tìm kiếm, lọc và quản lý trạng thái tài khoản.

**Actor:** Quản lý viên  
**Yêu cầu:** Đăng nhập với vai trò quản lý viên

## Flowchart - Xem Danh Sách

```mermaid
flowchart TD
    Start([Quản lý viên truy cập trang Quản lý người dùng]) --> CheckAuth{Đã đăng nhập<br/>vai trò quản lý viên?}
    CheckAuth -->|Không| RedirectLogin[Chuyển hướng tới trang đăng nhập]
    RedirectLogin --> End1([Kết thúc])
    
    CheckAuth -->|Có| LoadUsers[Load danh sách người dùng]
    LoadUsers --> DisplayList[Hiển thị danh sách:<br/>- Email<br/>- Tên<br/>- Vai trò Reader/Librarian/Admin<br/>- Ngày tham gia<br/>- Trạng thái Kích hoạt/Vô hiệu hóa]
    DisplayList --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style End1 fill:#ffcdd2
```

## Flowchart - Tìm Kiếm

```mermaid
flowchart TD
    Start([Quản lý viên nhập từ khóa tìm kiếm]) --> InputKeyword[Nhập từ khóa:<br/>email hoặc tên]
    InputKeyword --> Search[Thực hiện tìm kiếm]
    Search --> CheckResults{Có kết quả?}
    
    CheckResults -->|Không| ShowNoResults[Hiển thị:<br/>Không tìm thấy người dùng]
    ShowNoResults --> End1([Kết thúc])
    
    CheckResults -->|Có| DisplayResults[Hiển thị kết quả tìm kiếm]
    DisplayResults --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style End1 fill:#fff9c4
    style ShowNoResults fill:#fff9c4
```

## Flowchart - Lọc Theo Vai Trò

```mermaid
flowchart TD
    Start([Quản lý viên chọn vai trò từ dropdown]) --> SelectRole[Chọn vai trò:<br/>Reader/Librarian/Admin/Tất cả]
    SelectRole --> Filter[Lọc danh sách theo vai trò]
    Filter --> DisplayFiltered[Hiển thị danh sách đã lọc]
    DisplayFiltered --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
```

## Flowchart - Vô Hiệu Hóa/Kích Hoạt

```mermaid
flowchart TD
    Start([Quản lý viên click Vô hiệu hóa/Kích hoạt]) --> CheckSelf{Là chính mình?}
    CheckSelf -->|Có| ErrorSelf[Hiển thị lỗi:<br/>Không thể vô hiệu hóa<br/>chính mình]
    ErrorSelf --> End1([Kết thúc])
    
    CheckSelf -->|Không| ShowConfirm[Hiển thị xác nhận]
    ShowConfirm --> UserConfirm{Người dùng<br/>xác nhận?}
    
    UserConfirm -->|Không| Cancel[Hủy thao tác]
    Cancel --> End1
    
    UserConfirm -->|Có| UpdateStatus[Cập nhật trạng thái tài khoản]
    UpdateStatus --> Success[Hiển thị thông báo:<br/>Cập nhật trạng thái thành công]
    Success --> Refresh[Làm mới danh sách]
    Refresh --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style End1 fill:#ffcdd2
    style ErrorSelf fill:#ffcdd2
    style Success fill:#c8e6c9
```

## Hiển Thị Thông Tin
- Email
- Tên
- Vai trò (Reader/Librarian/Admin)
- Ngày tham gia
- Trạng thái (Kích hoạt/Vô hiệu hóa)

## Chức Năng
- **Tìm kiếm:** Theo email/tên
- **Lọc:** Theo vai trò
- **Vô hiệu hóa/Kích hoạt:** Tài khoản người dùng

## Edge Cases
- Không có kết quả tìm kiếm
- Tìm kiếm kết hợp với lọc
- Vô hiệu hóa chính mình (không cho phép)
- Vô hiệu hóa tài khoản đang có đơn mượn hoạt động
