# 2.5.3 - Xem & Thanh Toán Khoản Phạt (Nhân Viên Thư Viện)

## Mô tả
Tính năng cho phép nhân viên thư viện xem và xác nhận/từ chối thanh toán khoản phạt từ độc giả.

**Actor:** Nhân viên thư viện  
**Yêu cầu:** Đăng nhập với vai trò nhân viên

## Flowchart - Xem Danh Sách

```mermaid
flowchart TD
    Start([Nhân viên truy cập trang Quản lý khoản phạt]) --> CheckAuth{Đã đăng nhập<br/>vai trò nhân viên?}
    CheckAuth -->|Không| RedirectLogin[Chuyển hướng tới trang đăng nhập]
    RedirectLogin --> End1([Kết thúc])
    
    CheckAuth -->|Có| LoadPenalties[Load danh sách khoản phạt<br/>chưa thanh toán]
    LoadPenalties --> DisplayList[Hiển thị danh sách:<br/>- Độc giả<br/>- Nguyên nhân phạt<br/>- Số tiền<br/>- Ngày phạt<br/>- Trạng thái]
    DisplayList --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style End1 fill:#ffcdd2
```

## Flowchart - Xem Chi Tiết

```mermaid
flowchart TD
    Start([Nhân viên click vào khoản phạt]) --> LoadDetail[Load chi tiết khoản phạt]
    LoadDetail --> DisplayDetail[Hiển thị chi tiết:<br/>- Độc giả<br/>- Nguyên nhân phạt<br/>- Số tiền<br/>- Ngày phạt<br/>- Trạng thái<br/>- Ghi chú]
    DisplayDetail --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
```

## Flowchart - Xác Nhận Thanh Toán

```mermaid
flowchart TD
    Start([Nhân viên xem chi tiết khoản phạt]) --> CheckStatus{Trạng thái<br/>là Chờ xác nhận?}
    CheckStatus -->|Không| ErrorStatus[Hiển thị lỗi:<br/>Phiếu phạt không ở trạng thái<br/>chờ xác nhận]
    ErrorStatus --> End1([Kết thúc])
    
    CheckStatus -->|Có| VerifyAmount[Kiểm tra số tiền<br/>thanh toán có phù hợp?]
    VerifyAmount -->|Không phù hợp| RejectFlow[Chuyển tới luồng từ chối]
    RejectFlow --> End1
    
    VerifyAmount -->|Phù hợp| ClickConfirm[Click Đã thanh toán]
    ClickConfirm --> UpdateStatus[Cập nhật trạng thái:<br/>Đã thanh toán]
    UpdateStatus --> Success[Hiển thị thông báo:<br/>Xác nhận thanh toán thành công]
    Success --> Refresh[Làm mới danh sách]
    Refresh --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style End1 fill:#ffcdd2
    style ErrorStatus fill:#ffcdd2
    style Success fill:#c8e6c9
```

## Flowchart - Từ Chối Thanh Toán

```mermaid
flowchart TD
    Start([Nhân viên click Từ chối]) --> CheckStatus{Trạng thái<br/>là Chờ xác nhận?}
    CheckStatus -->|Không| ErrorStatus[Hiển thị lỗi:<br/>Phiếu phạt không ở trạng thái<br/>chờ xác nhận]
    ErrorStatus --> End1([Kết thúc])
    
    CheckStatus -->|Có| ShowRejectForm[Hiển thị form từ chối]
    ShowRejectForm --> InputReason[Nhập lý do từ chối<br/>bắt buộc]
    InputReason --> Validate{Đã nhập lý do?}
    
    Validate -->|Chưa nhập| ErrorNoReason[Hiển thị lỗi:<br/>Vui lòng nhập lý do từ chối]
    ErrorNoReason --> InputReason
    
    Validate -->|Đã nhập| UpdateStatus[Cập nhật trạng thái:<br/>Từ chối<br/>Lý do từ chối: Giá trị đã nhập]
    UpdateStatus --> Success[Hiển thị thông báo:<br/>Đã từ chối thanh toán]
    Success --> Refresh[Làm mới danh sách]
    Refresh --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style End1 fill:#ffcdd2
    style ErrorNoReason fill:#ffcdd2
    style Success fill:#c8e6c9
```

## Validation Rules
- **Lý do từ chối:** Bắt buộc phải nhập

## Edge Cases
- Số tiền thanh toán không khớp với số tiền phạt
- Độc giả chưa thanh toán nhưng nhấn "Đã thanh toán"
- Lý do từ chối trống
- Phiếu phạt không ở trạng thái "Chờ xác nhận"
