# 2.2.3 - Xem Danh Sách Sách

## Mô tả
Tính năng cho phép tất cả người dùng (không cần đăng nhập) xem danh sách sách với các chức năng tìm kiếm, lọc, sắp xếp.

**Actor:** Tất cả người dùng (không cần login)

## Flowchart - Xem Danh Sách

```mermaid
flowchart TD
    Start([Người dùng truy cập trang danh sách sách]) --> LoadBooks[Load danh sách sách]
    LoadBooks --> CheckEmpty{Có sách nào?}
    CheckEmpty -->|Không| ShowEmpty[Hiển thị:<br/>Chưa có sách nào]
    ShowEmpty --> End1([Kết thúc])
    
    CheckEmpty -->|Có| DisplayList[Hiển thị danh sách:<br/>- Tên sách<br/>- Tác giả<br/>- Năm xuất bản<br/>- Thể loại<br/>- Số lượng có sẵn<br/>- Số lượng đang mượn]
    DisplayList --> Paginate[Phân trang:<br/>10 sách/trang]
    Paginate --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style End1 fill:#fff9c4
    style ShowEmpty fill:#fff9c4
```

## Flowchart - Tìm Kiếm

```mermaid
flowchart TD
    Start([Người dùng nhập từ khóa tìm kiếm]) --> InputKeyword[Nhập từ khóa:<br/>tên sách hoặc tác giả]
    InputKeyword --> Search[Thực hiện tìm kiếm]
    Search --> CheckResults{Có kết quả?}
    
    CheckResults -->|Không| ShowNoResults[Hiển thị:<br/>Không tìm thấy kết quả]
    ShowNoResults --> End1([Kết thúc])
    
    CheckResults -->|Có| DisplayResults[Hiển thị kết quả tìm kiếm]
    DisplayResults --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style End1 fill:#fff9c4
    style ShowNoResults fill:#fff9c4
```

## Flowchart - Lọc Theo Thể Loại

```mermaid
flowchart TD
    Start([Người dùng chọn thể loại từ dropdown]) --> SelectCategory[Chọn thể loại]
    SelectCategory --> Filter[Lọc sách theo thể loại]
    Filter --> CheckResults{Có sách nào<br/>thuộc thể loại?}
    
    CheckResults -->|Không| ShowNoResults[Hiển thị:<br/>Không có sách thuộc thể loại này]
    ShowNoResults --> End1([Kết thúc])
    
    CheckResults -->|Có| DisplayFiltered[Hiển thị danh sách<br/>đã lọc]
    DisplayFiltered --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style End1 fill:#fff9c4
    style ShowNoResults fill:#fff9c4
```

## Flowchart - Sắp Xếp

```mermaid
flowchart TD
    Start([Người dùng chọn tiêu chí sắp xếp]) --> SelectSort[Chọn tiêu chí:<br/>- Tên A-Z<br/>- Năm xuất bản mới nhất<br/>- Lượt mượn phổ biến nhất]
    SelectSort --> Sort[Thực hiện sắp xếp]
    Sort --> DisplaySorted[Hiển thị danh sách<br/>đã sắp xếp]
    DisplaySorted --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
```

## Flowchart - Kết Hợp Tìm Kiếm + Lọc + Sắp Xếp

```mermaid
flowchart TD
    Start([Người dùng sử dụng nhiều chức năng]) --> Search[Thực hiện tìm kiếm]
    Search --> Filter[Lọc theo thể loại]
    Filter --> Sort[Sắp xếp theo tiêu chí]
    Sort --> Display[Hiển thị kết quả<br/>đã tìm kiếm + lọc + sắp xếp]
    Display --> Paginate[Phân trang kết quả]
    Paginate --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
```

## Hiển Thị Thông Tin
- Tên sách
- Tác giả
- Năm xuất bản
- Thể loại
- Số lượng có sẵn
- Số lượng đang mượn

## Chức Năng
- **Tìm kiếm:** Theo tên sách hoặc tác giả
- **Lọc:** Theo thể loại
- **Sắp xếp:** 
  - Tên (A-Z)
  - Năm xuất bản (Mới nhất)
  - Lượt mượn (Phổ biến nhất)
- **Phân trang:** 10 sách trên 1 trang

## Edge Cases
- Không có kết quả tìm kiếm
- Danh sách rỗng
- Kết hợp tìm kiếm + lọc + sắp xếp
- Thể loại không có sách nào
