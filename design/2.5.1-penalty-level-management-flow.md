# 2.5.1 - Quản lý mức phạt

## Mô tả
Tính năng cho phép quản lý viên quản lý các mức phạt trong hệ thống: xem, thêm, sửa, xóa.

**Actor:** Quản lý viên  
**Yêu cầu:** Đăng nhập với vai trò quản lý viên

## Flowchart - Xem Danh Sách

```mermaid
flowchart TD
    Start([Quản lý viên truy cập trang quản lý mức phạt]) --> CheckAuth{Đã đăng nhập<br/>vai trò quản lý viên?}
    CheckAuth -->|Không| RedirectLogin[Chuyển hướng tới trang đăng nhập]
    RedirectLogin --> End1([Kết thúc])
    
    CheckAuth -->|Có| LoadPenalties[Load danh sách mức phạt]
    LoadPenalties --> DisplayTable[Hiển thị danh sách dạng bảng:<br/>- Tên mức phạt<br/>- Số tiền<br/>- Ngày phạt<br/>Có thể sửa trực tiếp]
    DisplayTable --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style End1 fill:#ffcdd2
```

## Flowchart - Thêm Mức Phạt

```mermaid
flowchart TD
    Start([Quản lý viên click Thêm mức phạt]) --> ShowForm[Hiển thị form thêm mức phạt]
    ShowForm --> InputData[Nhập thông tin:<br/>- Tên mức phạt<br/>- Số tiền<br/>- Ngày phạt<br/>mặc định: ngày hiện tại]
    InputData --> Validate{Validate dữ liệu}
    
    Validate -->|Tên trống| ErrorNameEmpty[Hiển thị lỗi:<br/>Tên mức phạt không được để trống]
    ErrorNameEmpty --> InputData
    
    Validate -->|Tên >25 ký tự| ErrorNameLength[Hiển thị lỗi:<br/>Tên mức phạt tối đa 25 ký tự]
    ErrorNameLength --> InputData
    
    Validate -->|Số tiền <=0 hoặc không phải số| ErrorAmount[Hiển thị lỗi:<br/>Số tiền phải >0]
    ErrorAmount --> InputData
    
    Validate -->|Ngày phạt không hợp lệ| ErrorDate[Hiển thị lỗi:<br/>Ngày phạt không hợp lệ]
    ErrorDate --> InputData
    
    Validate -->|Tất cả hợp lệ| CreatePenalty[Tạo mức phạt mới]
    CreatePenalty --> Success[Hiển thị thông báo:<br/>Thêm mức phạt thành công]
    Success --> Refresh[Làm mới danh sách]
    Refresh --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style ErrorNameEmpty fill:#ffcdd2
    style ErrorNameLength fill:#ffcdd2
    style ErrorAmount fill:#ffcdd2
    style ErrorDate fill:#ffcdd2
    style Success fill:#c8e6c9
```

```mermaid
flowchart TD
    Start([Quản lý viên sửa trực tiếp trên bảng]) --> EditData[Sửa thông tin:<br/>- Tên mức phạt<br/>- Số tiền<br/>- Ngày phạt]
```

## Flowchart - Xóa Mức Phạt

```mermaid
flowchart TD
    Start([Quản lý viên click Xóa trên bảng]) --> ShowConfirm[Hiển thị xác nhận xóa]
    ShowConfirm --> UserConfirm{Người dùng<br/>xác nhận?}
    
    UserConfirm -->|Không| Cancel[Hủy xóa]
    Cancel --> End1([Kết thúc])
    
    UserConfirm -->|Có| CheckInUse{Mức phạt đang<br/>được sử dụng?}
    CheckInUse -->|Có| ErrorInUse[Hiển thị cảnh báo:<br/>Mức phạt đang được sử dụng<br/>Bạn vẫn muốn xóa?]
    ErrorInUse --> UserConfirm2{Người dùng<br/>xác nhận lại?}
    
    UserConfirm2 -->|Không| Cancel
    UserConfirm2 -->|Có| DeletePenalty[Xóa mức phạt]
    
    CheckInUse -->|Không| DeletePenalty
    
    DeletePenalty --> Success[Hiển thị thông báo:<br/>Xóa mức phạt thành công]
    Success --> Refresh[Làm mới danh sách]
    Refresh --> End([Kết thúc])
    
    style Start fill:#e1f5ff
    style End fill:#c8e6c9
    style End1 fill:#ffcdd2
    style ErrorInUse fill:#fff9c4
    style Success fill:#c8e6c9
```

## Validation Rules
- **Tên mức phạt:** Không được để trống, tối đa 25 ký tự
- **Số tiền:** Phải > 0, kiểu số
- **Ngày phạt:** Ngày hợp lệ (mặc định là ngày hiện tại)

## Edge Cases
- Tên mức phạt quá dài (>25 ký tự)
- Số tiền <= 0
- Ngày phạt không hợp lệ
- Mức phạt đang được sử dụng trong phiếu phạt (có thể vẫn cho xóa nhưng cần cảnh báo)
